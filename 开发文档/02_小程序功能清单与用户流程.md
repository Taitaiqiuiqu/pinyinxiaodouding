# 小程序功能清单与用户流程

## 1. 核心用户角色
- 儿童用户（3–8 岁）
- 家长用户（监管者）

---
## 2. 用户主流程（儿童）

1. 打开小程序 → 欢迎动画 + 语音
2. 年龄选择（卡通角色引导）
3. **主页面选择** ← 新增：功能模块选择
   - 课程学习（3-8岁）
   - 游戏训练（3-8岁，分龄开放）
   - 手写练习（5-8岁）
   - 家长设置（全年龄）
4. 进入对应学习路径
5. 课程学习 / 游戏训练
6. 获得正向反馈
7. 达到使用时长 → 自动锁定

---
## 3. 用户主流程（家长）

1. 首次进入 → 家长提示
2. 设置每日使用时长
3. 超时解锁（可选）

---
## 4. 功能模块清单

### 基础功能
- 年龄信息收集
- 家长监管（时长限制）

### **主页面导航** ← 新增
- 功能模块卡片展示
- 分龄功能筛选（3-4岁：3个卡片，5-8岁：4个卡片）
- 统一入口设计

### 学习模块
- 在线课程（分龄开放）
- 基础跟读训练
- 拼音儿歌

### 游戏模块
- 拼音点点乐（3–4 岁）
- 拼音拼图（4–5 岁）
- 拼音词语连连看（5–6 岁）

### 反馈模块
- 成功鼓励
- 错误安抚
- 进度完成提示

---
## 5. 分龄功能开放规则

| 年龄 | 可用模块 |
|---|---|
| 3–4 | 启蒙课程 / 点点乐 |
| 4–5 | + 拼音拼图 |
| 5–6 | + 连连看 |
| 6–8 | 综合应用 / 阅读 |
