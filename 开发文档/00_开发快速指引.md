### 1.3 目录布局兼容说明（新增）

为兼容现有工程与不同团队习惯，本项目支持两种源码布局，AI 编译器与自动化脚本需按下列顺序查找并适配：

- **优先查找（推荐）**：
  1. `src/` 根目录（与文档约定一致）  
  2. 项目根目录下的 `pages/`, `components/`, `assets/` 等（向后兼容已存在项目）

- **实现约定**：
  - 所有自动化工具（构建脚本、AI 编译器）在生成或验证模块时，应先尝试在 `src/` 下创建/查找文件；如果不存在，再回退到项目根目录结构。
  - 在模块 README（`module_README_TEMPLATE.md`）中必须标注模块的实际路径（`src/...` 或 根目录 `pages/...`）。
  - 对于路径敏感的引用（例如 `/static/`），保持相对引用策略并在 README 中说明运行时根路径假设。

- **迁移建议（非必需）**：
  - 若团队决定统一到 `src/`，建议通过一次性迁移脚本（移动文件 + 更新引用 + CI 回归）完成；否则采用本兼容策略以降低破坏性风险。

## 三、组件使用规范

### 3.1 RoleGuide 组件
```vue
<template>
  <view class="role-guide">
    <image :src="roleImage" class="role-image"/>
    <view class="speech-bubble" v-if="guideText">
      {{ guideText }}
    </view>
  </view>
</template>

<script>
export default {
  props: {
    roleType: {
      type: String,
      default: 'idle',  // idle/point/speak/cheer/think
    },
    guideText: String,
    age: Number
  },
  computed: {
    roleImage() {
      return `/static/images/role/role_${this.roleType}.png`
    }
  }
}
</script>
```

### 3.2 AudioPlayer 组件
```javascript
// 音频播放优先级
// 1. 拼音跟读/引导语音（最高）
// 2. 反馈音效
// 3. 背景音乐（最低，可随时打断）

// 使用示例
AudioPlayer.play({
  type: 'phonics',  // guide/phonics/word/feedback
  file: 'phonics_a_3-4_01.mp3',
  onComplete: callback
})
```

## 五、分龄功能实现

### 5.1 年龄判断逻辑
```javascript
// utils/age.ts
export const getAgeGroup = (age) => {
  if (age >= 3 && age <= 4) return '3-4'
  if (age >= 4 && age <= 5) return '4-5'
  if (age >= 5 && age <= 6) return '5-6'
  if (age >= 6 && age <= 8) return '6-8'
}
```

### 5.2 功能开放规则
| 年龄 | 开放功能 |

| 4-5 | + 拼音拼图 |
| 5-6 | + 连连看 |

## 七、常见问题

### Q1: 如何选择角色状态？
A: 根据页面行为选择：
- 等待状态：role_idle
- 引导点击：role_point
- 讲解跟读：role_speak
- 成功反馈：role_cheer
- 错误安抚：role_think

### Q2: 音频播放冲突怎么办？
A: AudioPlayer会自动管理优先级，新播放的音频会自动暂停当前播放的低优先级音频。

### Q3: 如何新增一个拼音课程？
A: 按命名规范添加音频文件，然后在课程配置中添加对应条目，无需修改页面代码。

## 八、代码示例

### 课程学习页示例
```vue
<template>
  <view class="page learning-page">
    <!-- 顶部区域 -->
    <view class="top-bar">
      <image src="/static/images/ui/back.png" @tap="goBack"/>
    </view>

    <!-- 核心内容区 -->
    <view class="content-area">
      <view class="pinyin-card" @tap="playPhonics">
        <text class="pinyin-text">{{ pinyin }}</text>
      </view>
    </view>

    <!-- 引导区 -->
    <RoleGuide
      roleType="speak"
      :guideText="guideText"
      :age="childAge"
    />
  </view>
</template>

<script>
import { mapState } from 'vuex'
import RoleGuide from '@/components/RoleGuide'
import AudioPlayer from '@/components/AudioPlayer'

export default {
  components: { RoleGuide, AudioPlayer },

  computed: {
    ...mapState(['childAge'])
  },

  data() {
    return {
      pinyin: 'a',
      guideText: '跟我读：a'
    }
  },

  methods: {
    playPhonics() {
      const ageGroup = getAgeGroup(this.childAge)
      AudioPlayer.play({
        type: 'phonics',
        file: `phonics_${this.pinyin}_${ageGroup}_01.mp3`
      })
    }
  }
}
</script>
```
