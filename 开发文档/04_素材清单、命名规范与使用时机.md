# 素材清单、命名规范与使用时机

## 1. 素材分类

### 图片素材
- 角色（role）
- 小手引导（hand）
- UI 装饰（ui）

### 音频素材
- 引导语音（guide）
- 拼音跟读（phonics）
- 词语发音（word）
- 正向反馈（feedback_success）
- 失败安抚（feedback_fail）

---
## 2. 命名规范

### 图片命名
```
role_idle.png
role_point.png
role_speak.png
role_cheer.png
role_think.png
hand_click.png
hand_drag.png
```

### 音频命名
```
guide_welcome_3-8_01.mp3
phonics_ba_4-5_01.mp3
word_baba_4-6_01.mp3
feedback_success_3-8_01.mp3
feedback_fail_3-6_01.mp3
```

---
## 3. 素材存放位置

```text
assets/
 ├─ images/
 │   ├─ role/
 │   ├─ hand/
 │   └─ ui/
 └─ audio/
     ├─ guide/
     ├─ phonics/
     ├─ word/
     └─ feedback/
```

---
## 4. 使用时机说明

- 页面首次进入 → guide 音频 + role_idle
- 需要点击 / 拖拽 → role_point + hand_* + guide
- 跟读 → role_speak + phonics
- 成功 → role_cheer + feedback_success
- 失败 → role_think + feedback_fail

---
## 5. 最小素材集（MVP）
- 角色图：5 张
- 小手图：2 张
- 引导音频：10 条
- 拼音音频：声母 + 单韵母
- 反馈音频：成功 / 失败 各 3 条
