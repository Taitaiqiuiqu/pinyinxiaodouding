# 页面设计规范（UI / UX Design Specification）

> 本文档用于统一儿童汉语拼音学习小程序的页面设计风格、布局规则与交互规范，确保所有页面 **低认知负担、强引导性、高一致性**，并可直接指导 AI 编译器生成前端页面。

---
## 一、设计目标与原则

### 1. 目标人群
- 核心用户：3–8 岁儿童
- 辅助用户：家长

### 2. 设计总原则
- **少文字，多图形，多语音**
- **一步一操作，不出现复杂选择**
- **所有页面都可“不识字使用”**
- **重要操作 = 角色 + 语音 + 小手引导**

---
## 二、页面整体结构规范（通用）

### 1. 页面分区标准

```
┌──────────────────────┐
│ 顶部区域（状态/返回） │  ≤10%
├──────────────────────┤
│                      │
│  核心内容区           │  ≥65%
│                      │
├──────────────────────┤
│  引导区（角色+语音）  │  15–25%
└──────────────────────┘
```

#### 顶部区域
- 返回按钮（图标，不用文字）
- 不出现设置、菜单（避免误触）

#### 核心内容区
- 当前学习 / 游戏内容
- 单一任务原则（一次只做一件事）

#### 引导区
- 卡通角色（固定位置）
- 语音气泡（短句）

---
## 三、卡通角色使用规范

### 1. 角色位置
- **默认：页面右下角**
- 不遮挡主要操作区域

### 2. 角色状态与页面行为映射

| 页面行为 | 使用角色图 | 说明 |
|---|---|---|
| 页面等待 | role_idle | 静态陪伴 |
| 引导点击 | role_point | 指向操作区域 |
| 跟读 / 讲解 | role_speak | 张嘴说话 |
| 成功反馈 | role_cheer | 鼓掌 / 跳跃 |
| 错误安抚 | role_think | 歪头思考 |

---
## 四、小手引导规范

### 1. 使用规则
- **仅 3–6 岁页面默认开启**
- 6–8 岁默认关闭（可选开启）

### 2. 小手类型

| 场景 | 小手图 |
|---|---|
| 点击 | hand_click |
| 拖拽 | hand_drag |

### 3. 动画规则
- 循环慢速动画（1.2–1.5s）
- 操作完成后立即隐藏

---
## 五、颜色与视觉规范

### 1. 主色建议
- 主色：#4CC9F0（明亮蓝）
- 辅色：#FFD166（柔和黄）
- 成功：#06D6A0
- 警示（不用红）：#FF9F1C

> 禁止使用：大面积纯红 / 黑色背景

### 2. 对比度
- 背景 vs 内容 ≥ WCAG AA
- 避免花纹背景

---
## 六、字体与文字规范

### 1. 字体
- 中文：系统默认圆体 / 思源圆体
- 禁止使用细字体

### 2. 字号规范

| 内容 | 字号 |
|---|---|
| 拼音 / 核心内容 | 32–40px |
| 引导语 | 24–28px |
| 家长提示 | 18–20px |

---
## 七、交互规范

### 1. 点击热区
- 最小点击区域：**64×64 px**
- 卡片间距 ≥ 16px

### 2. 反馈规则
- 点击必有：
  - 动画变化
  - 音效 / 语音

---
## 八、页面类型规范（示例）

### 1. 课程学习页
- 1 个拼音 / 1 个音节
- 点击 → 跟读 → 成功反馈

### 2. 游戏页
- 不出现倒计时（低龄）
- 错误不扣分，只提示

### 3. 家长页
- 与儿童页面完全风格隔离
- 颜色偏中性

---
## 九、AI 编译器页面生成约束

AI 在生成页面时必须遵循：
1. 固定三段式布局
2. 必须引入 RoleGuide 组件
3. 不得出现复杂表单
4. 所有操作必须可被语音解释

---
## 十、验收标准

- 3 岁儿童可在无成人帮助下完成一次操作
- 任何页面 ≤ 2 步完成目标
- 页面风格在不同模块间保持一致
