# 页面设计规范（UI / UX Design Specification）

> 本文档用于统一儿童汉语拼音学习小程序的页面设计风格、布局规则与交互规范，确保所有页面 **低认知负担、强引导性、高一致性**，并可直接指导 AI 编译器生成前端页面。

---
## 一、设计目标与原则

### 1. 目标人群
- 核心用户：3–8 岁儿童
- 辅助用户：家长

### 2. 设计总原则
- **少文字，多图形，多语音**
- **一步一操作，不出现复杂选择**
- **所有页面都可“不识字使用”**
- **重要操作 = 语音 + 小手引导（条件显示）**

---
## 二、页面整体结构规范（通用）

### 1. 页面分区标准

```
┌──────────────────────┐
│ 顶部区域（状态/返回） │  ≤10%
├──────────────────────┤
│                      │
│  核心内容区           │  ≥90%
│                      │
└──────────────────────┘
```

#### 顶部区域
- 返回按钮（图标，不用文字）
- 不出现设置、菜单（避免误触）

#### 核心内容区
- 当前学习 / 游戏内容
- 单一任务原则（一次只做一件事）
- 条件显示的辅助引导元素（如小手提示）

---
## 三、小手引导规范

### 1. 使用规则
- **仅 3–6 岁页面默认开启**
- 6–8 岁默认关闭（可选开启）

### 2. 小手类型

| 场景 | 小手图 |
|---|---|
| 点击 | hand_click |
| 拖拽 | hand_drag |

### 3. 动画规则
- 循环慢速动画（1.2–1.5s）
- 操作完成后立即隐藏

---
## 五、颜色与视觉规范

### 1. 主色建议 - 只使用红、黄、蓝三种颜色
- 主色：#FF476F（明亮红色，活泼可爱）
- 辅助色1：#FBBF24（明亮黄色，用于提示、游戏模块）
- 辅助色2：#3B82F6（明亮蓝色，用于成功状态、成就模块）
- 错误：#FF476F（明亮红色，用于错误提示）

> 禁止使用：除红、黄、蓝外的其他颜色
> 推荐使用：明亮高饱和度的红、黄、蓝纯色，营造活泼可爱的氛围

### 2. 对比度
- 背景 vs 内容 ≥ WCAG AA
- 避免花纹背景

### 3. 圆角规范
- 所有组件使用大圆角设计，营造柔软安全的感觉
- 基础圆角：32rpx
- 卡片圆角：64rpx
- 按钮圆角：48rpx

### 4. 阴影规范
- 使用柔和模糊的阴影，避免硬朗线条
- 卡片阴影：0 12rpx 40rpx rgba(0, 0, 0, 0.06)
- 按钮阴影：0 8rpx 32rpx rgba(255, 107, 157, 0.2)

---
## 六、界面布局规范

### 1. 色块拼接式设计原则
- **主背景**：使用纯白色 (#FFFFFF) 或极浅米白色 (#FAFAFA)，干净简洁
- **功能区块**：将不同功能模块放置在不同颜色的纯色块上
- **大圆角设计**：色块和卡片使用大圆角，营造漂浮的彩色积木效果
- **色彩搭配**：采用明亮、高饱和度的纯色块，符合儿童审美

### 2. 色块使用规范 - 只使用红、黄、蓝三种颜色
- **模块区分**：不同功能模块使用不同颜色的色块
  - 声母学习：红色块
  - 韵母游戏：蓝色块
  - 奖励区：黄色块
  - 创意区：红色块
- **色块样式**：
  - 圆角：64rpx
  - 阴影：0 12rpx 40rpx rgba(0, 0, 0, 0.06)
  - 间距：色块之间保持充足间距，避免拥挤

### 3. 布局层次
- 顶部：仅保留必要的返回按钮
- 中部：核心内容区，占比 ≥70%，使用色块拼接布局
- 底部：简洁的导航或操作按钮

### 4. 简化布局原则
- 采用简约框架设计，减少视觉干扰
- 核心内容居中显示，避免复杂布局
- 元素间距充足，避免拥挤感
- 突出主要操作，减少次要元素

---
## 七、字体与文字规范

### 1. 字体
- 中文：系统默认圆体 / 思源圆体
- 禁止使用细字体

### 2. 字号规范

| 内容 | 字号 |
|---|---|
| 拼音 / 核心内容 | 32–40px |
| 引导语 | 24–28px |
| 家长提示 | 18–20px |

---
## 七、交互规范

### 1. 点击热区
- 最小点击区域：**64×64 px**
- 卡片间距 ≥ 16px

### 2. 反馈规则
- 点击必有：
  - 动画变化
  - 音效 / 语音

---
## 八、页面类型规范（示例）

### 1. 课程学习页
- 1 个拼音 / 1 个音节
- 点击 → 跟读 → 成功反馈

### 2. 游戏页
- 不出现倒计时（低龄）
- 错误不扣分，只提示

### 3. 家长页
- 与儿童页面完全风格隔离
- 颜色偏中性

---
## 九、AI 编译器页面生成约束

AI 在生成页面时必须遵循：
1. 简化的两段式布局
2. 不得出现复杂表单
3. 所有操作必须可被语音解释

---
## 十、验收标准

- 3 岁儿童可在无成人帮助下完成一次操作
- 任何页面 ≤ 2 步完成目标
- 页面风格在不同模块间保持一致
