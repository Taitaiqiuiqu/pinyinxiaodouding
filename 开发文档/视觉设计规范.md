# 视觉设计规范（童趣可爱主题）

目的：提供一份充满童趣与活力的视觉规范，打造色彩丰富、活泼可爱的幼儿友好界面，增强对幼儿的视觉吸引力。主题：童趣可爱（多彩、圆润、温馨、梦幻）。

1. 颜色（Design tokens）
- 主色（Brand Primary）：`#ff7eb3`（粉嫩主色，温暖可爱）
- 辅助主色：`#ff9a56`（橙色活力，充满能量）
- 强调色1（Accent 1）：`#ffd93d`（明亮黄色，阳光快乐）
- 强调色2（Accent 2）：`#6bcf7f`（清新绿色，自然生机）
- 强调色3（Accent 3）：`#a78bfa`（梦幻紫色，童话氛围）
- 强调色4（Accent 4）：`#4ecdc4`（青色清新，活泼灵动）
- 柔和背景：`#fff9f5`（温暖米白，舒适柔和）
- 卡片背景：`#ffffff`（纯白卡片，干净明亮）
- 渐变背景1：`linear-gradient(135deg, #ffecd2 0%, #fcb69f 100%)`（暖色渐变）
- 渐变背景2：`linear-gradient(135deg, #a8edea 0%, #fed6e3 100%)`（清新渐变）
- 文本主色：`#2d3436`
- 辅助文本：`#636e72`
- 错误/警示：`#ff6b6b`（柔和红色，不吓人）

2. 字体与层级
- 标题（Title）：32–40rpx，粗体（700），可使用圆体或手写风格字体
- 副标题（Subtitle）：16–18rpx，中粗（500），颜色使用辅助文本
- 正文（Body）：15rpx，行高 22–26rpx，常规（400）
- 小字号（Caption）：13rpx
- 强调文本：可使用彩色字体（如主色或强调色）

3. 间距与尺寸（Spacing）
- 大间距：28rpx（用于卡片外边距，更宽松舒适）
- 中间距：16rpx（元素间距，呼吸感更强）
- 小间距：10rpx（微距）
- 圆角：大角 24rpx（更加圆润可爱），常规角 16rpx，小角 8rpx
- 按钮高度：52rpx（更大的触控区域，适合幼儿操作）
- 图标尺寸：大图标 64rpx，中图标 48rpx，小图标 32rpx
- 头像尺寸：大头像 180rpx，中头像 120rpx，小头像 80rpx

4. 阴影与浮层
- 全局轻阴影（soft）：`0 8rpx 24rpx rgba(255,126,179,0.12)`（粉嫩阴影）
- 卡片阴影：`0 12rpx 32rpx rgba(255,126,179,0.15)`（柔和浮起效果）
- 按钮阴影：`0 6rpx 20rpx rgba(255,154,86,0.25)`（活力阴影）
- 悬浮效果：`transform: translateY(-4rpx)` 配合阴影增强

5. 组件视觉规范（简要）
- Button（主操作）
  - 类名：`.btn-primary`
  - 背景：渐变背景（主色到辅助主色），白字，圆角 32rpx，阴影
  - 按压效果：scale(0.95)，阴影减弱
  - 禁用态：opacity 0.5，背景灰色 `#d1d5db`

- Button（次级操作）
  - 类名：`.btn-secondary`
  - 背景：白色，彩色边框（主色），彩色文字
  - 圆角 32rpx，轻微阴影

- Card（容器）
  - 类名：`.card`
  - 背景：卡片背景，圆角 16rpx，padding 16–24rpx，阴影
  - 可选：彩色边框或渐变边框装饰

- RoleGuide（角色）
  - 使用圆形或圆角头像，尺寸 180rpx，带彩色渐变背景与气泡
  - 气泡字体稍大（18rpx），使用强调色浅色背景，圆角 20rpx
  - 加入活泼的 bob 动画（浮动），周期 2s
  - 可添加星星、爱心等装饰元素

- Age Option（选择卡）
  - 卡片化、渐变背景（多种颜色可选）、边距充足、按压反馈（微缩）
  - 文本使用加粗，中心对齐，字号 18rpx
  - 可添加可爱图标或装饰图案
  - 选中状态：高亮边框 + 放大效果

6. 动效
- 交互采用短动画（150–300ms）：按压缩放、渐变过渡、淡入淡出
- 按钮点击：scale(0.95) + 阴影减弱，反馈明显但不夸张
- 卡片悬浮：translateY(-4rpx) + 阴影增强，营造浮起感
- 角色动画：
  - bob 浮动：周期 2s，幅度 8rpx，轻松自然
  - blink 眨眼：周期 4s，快速眨眼增加可爱感
  - wave 挥手：周期 3s，欢迎时使用
- 页面切换：淡入淡出 + 轻微位移，平滑过渡
- 连续动画频率不宜过高，避免分散幼儿注意力
- 成功反馈：弹跳动画 + 星星/爱心粒子效果
- 错误反馈：轻微摇晃 + 柔和红色提示

7. 可访问性
- 文本对比度须满足基本可读性（标题与正文颜色对比）
- 按钮点击区域不少于 52×52 rpx（适合幼儿手指操作）
- 使用 `aria` 或小程序等价属性标注交互元素（便于无障碍扩展）
- 重要操作提供视觉 + 听觉双重反馈
- 避免过于复杂的动画，防止眩晕或注意力分散
- 色彩搭配考虑色盲友好，不仅依赖颜色区分状态

8. 装饰元素与插画风格
- 装饰元素：星星、爱心、云朵、彩虹、小动物等可爱图案
- 插画风格：扁平化 + 柔和阴影，色彩明亮但不刺眼
- 背景装饰：可添加淡淡的云朵、星星、泡泡等元素
- 边框装饰：虚线、波浪线、圆点等可爱边框
- 图标风格：圆润可爱，可添加表情或动作
- 装饰动画：缓慢飘动的云朵、闪烁的星星、上升的泡泡

9. 资源与命名约定
- 图片：`/static/images/<module>/...`（如 `static/images/age-select/age_option_3-4.png`）
- 音频：`/static/audio/<module>/...`（如 `static/audio/age-select/guide_age_survey_3-8_01.MP3`）
- 组件样式变量使用 `uni.scss` 中的 tokens（例如 `$brand-primary`、`$radius-lg`）
- 装饰图片：`/static/images/decorations/...`（如 `star.png`、`heart.png`、`cloud.png`）
- 插画资源：`/static/images/illustrations/...`

10. 使用示例（代码片段）
- 主按钮（渐变背景）：

```html
<button class="btn-primary">开始学习</button>
```

- 次级按钮（彩色边框）：

```html
<button class="btn-secondary">返回</button>
```

- 卡片（Age Option，带渐变背景）：

```html
<view class="card option gradient-pink">
  <text class="opt-label">3-4 岁</text>
  <view class="opt-icon">🌸</view>
</view>
```

- 角色气泡（带装饰）：

```html
<view class="role-guide">
  <view class="avatar">🐰</view>
  <view class="bubble">
    <text>你好呀！我是小兔子~</text>
    <view class="decoration-star">⭐</view>
  </view>
</view>
```

- 装饰元素示例：

```html
<view class="decoration-cloud">☁️</view>
<view class="decoration-star">⭐</view>
<view class="decoration-heart">💖</view>
```

11. 维护与扩展
- 将任何颜色/间距变动首先写入 `uni.scss`（设计 tokens），并在 `开发文档` 中记录变更历史。
- 任何新增组件需在 `src/components/README.md` 中补充视觉契约（使用示例、尺寸、边距）。
- 新增装饰元素或插画时，需保持风格统一，色彩协调。
- 定期审核色彩对比度和可访问性，确保对幼儿友好。
- 动画效果需在真机上测试，确保流畅不卡顿。
- 所有新增的视觉元素都应考虑对幼儿的吸引力，避免过于复杂或刺激的设计。
