# 平台兼容矩阵与已知限制（compatibility）

此文档记录各目标平台（微信小程序 / H5 / App）与功能之间的可用性、注意事项与临时方案，便于多人协作时明确期望。

## 支持矩阵（主要功能）

| 功能 / 平台 | MP-WEIXIN | H5 | APP (uni-app) | 备注 |
|---|---:|---:|---:|---|
| 云函数（wx.cloud） | ✔️ | ✖️ | ✖️ | 仅 MP-WEIXIN 原生支持；H5/APP 使用 mock 或替代后端 |
| 数据库（wx.cloud.database） | ✔️ | ✖️ | ✖️ | 同上 |
| 本地文件读写 | 受限 | 浏览器存储 | 原生能力 | 在小程序使用小程序 API，H5 使用 localStorage/IndexedDB |
| 音频播放 | ✔️ | ✔️ | ✔️ | 不同平台实现差异，使用统一 `AudioPlayer` 组件封装 |
| 条件编译 (#ifdef) | ✔️ | ✔️（编译层） | ✔️ | 推荐在代码中使用条件编译避免运行时错误 |
| 震动 / 原生能力 | ✔️ | 部分支持 | 支持 | 在 APP 使用原生插件或 uni API |

## 平台特性与实现建议

- **云开发**：所有对 `wx.cloud` 的引用必须通过 `src/services/cloud` 抽象层封装，并使用条件编译导入平台实现或 mock 实现。
- **H5 运行**：H5 环境应提供 mock 数据与示例素材，避免启动时报错。必要时在 README 中说明 H5 的功能限制（如不支持云函数）。
- **APP 运行**：APP 平台若需要云功能，考虑使用 uniCloud、自建后端或在云适配层实现替代方案。

## 已知问题与临时方案

- 问题：部分第三方 UI 或工具库不兼容 Vue3。  
  临时方案：为避免阻塞开发，优先使用基于 Vue3 的库或将 Vue2-only 功能隔离在单独小项目中重写。

- 问题：云函数依赖原生二进制模块（如某些 npm 包）。  
  临时方案：在云函数中避免使用需要编译的原生模块，或将复杂逻辑迁移到可运行在云环境的纯 JS 方案。

## 版本与验证

- 在每次升级 uni-app、HBuilderX、Vue 或 Node 版本前，先在 `compatibility.md` 中记录变更并做小范围验证（至少在 MP-WEIXIN 与 H5 环境上跑通主要流程）。

## 维护建议

- 将此文件作为活文档，任何团队成员发现平台相关的兼容问题，应提交 PR 并在表格中更新状态与临时方案。
